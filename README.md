# Factory-Project

# Factory Production Efficiency Analysis

## Project Description

This project analyzes machine data to better understand and predict machine failures. The project uses the AI4I 2020 Predictive Maintenance Dataset and examines information such as temperature, rotational speed, torque, tool wear, and machine failure.

## Dataset

The dataset comes from the UCI Machine Learning Repository.

Dataset: AI4I 2020 Predictive Maintenance Dataset

https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

The dataset contains 10,000 records and information about machine operation and failures.
